⚙️ RAG Pipeline

User Query → MiniLM Embed → FAISS Search → Top-3 Chunks → Chef Prompt → Llama 3.1 8B → JSON Response

Embeddings use sentence-transformers/all-MiniLM-L6-v2 (runs 100% locally, no API key needed). The FAISS index is persisted to faiss_index/ on first run for fast subsequent starts.

🚀 Quick Start

1
Install dependencies: pip install -r requirements.txt
2
Get a free Groq API key at console.groq.com/keys and create a .env file with GROQ_API_KEY=gsk_...
3
Run the server: python app.py — FAISS index auto-builds on first launch
4
Open http://localhost:5000 in your browser and start generating recipes!
💡 Tip: To extend the knowledge base, add recipes to recipes_data.txt following the existing format (separated by ---), then delete faiss_index/ and restart the server.
